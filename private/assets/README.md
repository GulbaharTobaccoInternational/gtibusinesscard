The approved vector artwork, integrity manifest and encrypted Gotham build bundle are source-controlled. Unencrypted fonts remain licensed, server-only assets excluded from Git. Git/Vercel prebuild restores them with the private GULBAHAR_FONT_KEY Secret and verifies their original hashes. For local use, install fonts with `npm run install:assets -- /absolute/path/to/B-Card-Assets`. Never put fonts in public/ or expose the key through NEXT_PUBLIC_* variables. Administrator key backup: the ignored .env.fonts.local file or your private secret manager.
